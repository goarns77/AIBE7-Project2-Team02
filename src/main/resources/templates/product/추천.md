# 리뷰 작성 화면 기획 메모

판매자가 거래를 마친 뒤, 주문 요청의 `status`가 `COMPLETED`가 되었을 때 구매자가 리뷰를 작성하는 화면을 만들기 위한 정리 문서입니다.

## 목표

- 거래 완료 후에만 리뷰를 작성할 수 있게 한다.
- 별점, 후기, 이미지 업로드를 지원한다.
- 나중에 로그인 정보와 연결해서 "내가 완료한 거래" 기준으로만 노출되도록 한다.
- 화면은 `templates/product/` 아래에서 관리한다.

## 필요한 흐름

1. 거래 완료 상태 확인
2. 리뷰 작성 가능 여부 판단
3. 리뷰 작성 화면 진입
4. 별점 입력
5. 후기 입력
6. 이미지 업로드 선택
7. 제출
8. 저장 후 상세 화면 또는 목록 화면으로 이동

## 먼저 정해야 할 것

### 1. 리뷰를 누구 기준으로 작성할지

- 구매자 기준으로 작성할지
- 판매자 기준으로 작성할지
- 현재 설명대로면 `구매자의 status가 COMPLETED`인 시점에 리뷰를 작성하는 구조로 보이므로, 리뷰 주체와 대상이 정확히 분리되어야 한다.

### 2. 리뷰 대상

- 판매자에 대한 리뷰인지
- 상품에 대한 리뷰인지
- 거래 주문 요청에 대한 리뷰인지

이 셋 중 하나를 먼저 확정해야 화면과 저장 구조가 흔들리지 않는다.

### 3. 작성 가능한 시점

- `COMPLETED` 상태일 때만 접근 가능
- 이미 리뷰를 작성했으면 다시 작성 불가
- 취소/진행 중 상태에서는 접근 불가

## 필요한 데이터

### 화면에 필요한 데이터

- 거래 ID
- 상품명 또는 판매 조건 정보
- 판매자 정보
- 구매자 정보
- 완료 일시
- 기존 리뷰 작성 여부

### 입력 데이터

- 별점: 보통 `1~5`
- 후기: 텍스트
- 이미지: 선택 사항

## 화면 구성 제안

### 상단 정보 영역

- 거래 대상 상품명
- 판매자 이름
- 거래 완료 일시
- 거래 상태

### 입력 영역

- 별점 선택 UI
- 후기 textarea
- 이미지 업로드 input
- 이미지 미리보기

### 제출 영역

- 작성하기 버튼
- 취소 버튼
- 이미 작성된 경우 수정 여부 표시

## 구현 순서 제안

### 1단계: 작성 가능 조건만 먼저 확인

- `COMPLETED` 상태만 리뷰 작성 페이지에 들어갈 수 있도록 한다.
- 이미 리뷰가 있는지 확인한다.

### 2단계: 화면 UI 작성

- 별점 입력
- 후기 입력
- 이미지 업로드

### 3단계: 제출 API 연결

- 별점, 후기, 이미지 전송
- 업로드 성공 시 리뷰 저장

### 4단계: 목록/상세 연동

- 완료된 거래 목록에서 "리뷰 작성" 버튼 노출
- 이미 작성한 거래는 "작성 완료"로 변경

## 추천 폼 방식

### 별점

- 별 5개 클릭 방식이 가장 직관적이다.
- 모바일에서도 터치하기 쉽다.

### 후기

- textarea 사용
- 최소/최대 길이 제한 필요

### 이미지

- `type="file"` 업로드
- 필요하면 여러 장 허용 가능
- 미리보기는 선택 사항

## 나중에 필요한 백엔드 요소

- 리뷰 엔티티
- 리뷰 저장 API
- 리뷰 조회 API
- 거래 완료 여부 검증
- 중복 리뷰 방지
- 이미지 저장소 처리

## 구현 시 주의점

- `COMPLETED`가 아닌 거래에는 리뷰 작성이 열리면 안 된다.
- 같은 거래에 리뷰가 중복 저장되면 안 된다.
- 이미지가 없어도 리뷰는 저장 가능해야 한다.
- 로그인 정보와 리뷰 대상이 일치해야 한다.
- 화면만 먼저 만들고 실제 저장은 나중에 붙여도 되도록 폼 구조를 단순하게 유지한다.

## 현재 단계에서의 권장 작업 순서

1. 리뷰 대상과 작성 주체를 확정한다.
2. `COMPLETED` 상태 검증 규칙을 정한다.
3. 리뷰 작성 페이지 템플릿을 만든다.
4. 별점/후기/이미지 UI를 만든다.
5. 저장 API를 연결한다.
6. 작성 완료 상태를 목록과 상세에 반영한다.

## 한 줄 정리

지금은 "거래 완료된 주문에 대해, 로그인한 사용자가 별점/후기/이미지를 남기는 리뷰 작성 화면"이 필요하고, 먼저 상태 검증과 대상 식별을 정한 뒤 UI와 저장 API를 붙이는 순서가 가장 안전하다.
