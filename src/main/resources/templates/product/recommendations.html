추천 응답 JSON 샘플

`GET /api/products/{productId}/order-requests/recommendations` 의 응답 구조를 확인하는 테스트 페이지입니다. 총점과 항목별 점수, 근거 태그를 한 번에 확인할 수 있습니다.

totalScore scoreItems reasonTag recommendations

실제 API 호출

상품 ID를 넣으면 추천 결과를 그대로 JSON으로 보여줍니다.

필드 설명

필드 설명
totalScore 추천 대상 주문 요청의 최종 점수입니다.
scoreItems 항목별 점수 목록입니다.
reasonTag 항목을 코드 레벨에서 식별하기 위한 태그입니다.
score 각 항목의 원점수입니다.
weight 현재 계산 시 적용된 재분배 가중치입니다.
contribution 최종 총점에 실제로 기여한 값입니다.
reason 화면에 보여줄 근거 문구입니다.
